# Lion Hills — быстрая дока

Одностраничный промо-лендинг ЖК **Lion Hills** (виллы и пентхаусы, Лісники, Київ). Тексты на **украинском** (`lang="ru"` в html — неточность). Статика без сборки: открывается `index.html` напрямую или любым static-сервером. Git-репозиторий (ветка `main`), деплой — lionhillsweb.vercel.app.

## Интро (лоадер)
Серый экран `#eaeaea`: в центре из blur выходит лого `.loader_logo` и уходит, затем на его месте фраза «Життя на висоті. Лісники, Київ» собирается по частям в одну строку (мобилка: все 3 части сменяют друг друга по одной, без точки), линия `.loader_frame` едет по краю экрана + счётчик %. Затем `.hero` (z-index выше лоадера, пока `html.is-loading`) открывается `clip-path` снизу вверх с параллаксом фото, следом строки заголовка (SplitText с маской), подзаголовок/хедер, кнопка. Лоадер **динамический**: линия и % идут за `window.loadProgress()` (критичный набор, см. «Загрузка медиа»), со сглаживанием и не быстрее одного круга за 2.4с; шторка стартует, когда линия дошла до 100% (+0.3с). В конце лоадер удаляется, снимается `is-loading`, стартует Lenis. Без GSAP или при reduced-motion лоадера нет (`bail()`).
- Мобилка: «разблюр» без анимации `filter` (в iOS Safari рывком становился чётким): `intro()` клонирует каждую `.loader_part` в `.loader_ghost` (статичный `blur(5px)`, светлый цвет, своя композит-плоскость), и копия кроссфейдится в чёткий текст — анимируется только `opacity`. Десктоп — как раньше, `filter: blur()`.
- Пауза таймлайна сделана через `tl.call` + `tl.pause()`: `addPause` с колбэком в GSAP 3.13 колбэк не вызывал.
- Headless Chrome с `--virtual-time-budget` не годится для проверки таймлайна: виртуальное время бежит быстрее кадров GSAP.

## Загрузка медиа
Все `<img>`/`<video>` ниже hero — с `data-src` вместо `src` (без `src` новые медиа не добавлять: загрузит только код из `scripts.js`, блок «Media loading»).
1. **Критичное** (грузится во время лоадера, параллельно) — `<link rel="preload">` в `<head>`: Aeonik Pro Regular + Medium, `hero2_compressed.jpg` / на мобилке `hero_mob.JPG` (через `media`); плюс `data-load="critical"`: `LH_arch.webm`, 1-й слайд «Концепції» (`Location.webm`), 1-я карточка клабхауса (SPA), 1-е видео галереи вилл (`terrace.webm`), `build1.mp4`, обложки 5 сторис вилл (картинки ещё и `decode()`). Видео — до `canplaythrough`. `window.criticalReady` + `window.loadProgress()` (0..1), общий лимит `CRITICAL_MAX` = 15с.
   - На мобилке `data-load-mobile` переопределяет `data-load` (`loadGroup()` в `scripts.js`): все `critical` там `queue`, критичное = только шрифты + `hero_mob.JPG`, счётчик лоадера идёт по таймеру. Причина: iOS не буферизует незапущенные видео, лоадер висел на ~88% до `CRITICAL_MAX`. Очередь и подгрузка блоков (`near`) на мобилке ждут `loaderDone` — событие `loader:done` из `animations.js` (старт шторки или `bail()`), чтобы загрузка не дёргала текст лоадера.
2. **Очередь** — `data-load="queue"`, по одному в порядке страницы после `criticalReady`: первый слайд остальных `.gallery` / `.carousel`, `build2`. Следующий файл — после `canplaythrough`/`load` (или 10с).
3. **Остальное** — слайды `.gallery`/`.carousel` целиком, когда блок в ~1 экране (`rootMargin: 100%`); `.stories` сами грузят текущий + следующий слайд (с `preload='auto'`), когда рядом; плюс когда первая вилла в ~1 экране, все слайды всех вилл грузятся фоном по одному по порядку. Клик по вкладке галереи подгружает её сразу.
- Inter (Google Fonts) удалён — не использовался. PP Hatton не в preload (только лого).

## Система анимаций (`data-anim`)
- `hero-title`, `hero-fade`, `hero-header` — анимирует `intro()`
- `lines` — заголовки; обычный fade-up, как `fade`
- `scrub` — абзац «заливается» по словам при скролле
- `fade` / `fade-only` — появление с подъёмом / без
- `stagger` — дети контейнера по очереди
- `count` — цифры в `.lot_main` / `.lot_terrace` считаются от 0
- Скрытие до старта GSAP через `html.js-anim`; инлайн-скрипт ставит `js-anim` и `is-loading` вместе, только если нет reduced-motion.
- `footerReveal()` — scrub: футер расширяется (`--inset` 2.5vw→0.5vw, мобилка 12px→6px) и съезжает вниз, открывая `.outro`. CSS по умолчанию = конечное состояние.
- `setupSnap()` — пошаговый скролл по `.types .stories`, только desktop с мышью и Lenis.

## Конвенции
- Классы BEM-подобные через подчёркивание: `block_element` (`gallery_tab`, `stories_seg`), состояния `active`, `done`, `is-open`, `is-visible`.
- JS — ES5-стиль (`var`, `function`, IIFE), без модулей и зависимостей кроме CDN.
- Комментарии короткие, на английском.
- Кнопки-CTA: класс `.btn-soft` + свой класс для цвета/позиции. Цвет фона — через `--btn-bg`. Hover: `scale: 0.95` (свойство `scale`, не `transform`). Углы — `corner-shape: superellipse(1.5)`, без поддержки радиус ×0.752.
- Мобилка: breakpoint 767px и в CSS, и в JS (`isMobile`). Кнопка «Меню» в hero везде открывает стеклянный `.drawer` (на мобилке во всю ширину с отступом 12px), пилюля — своё меню.
- Мобилка: пилюля `.sticky_header` внизу экрана (как плавающий футер), на 10% меньше (бар 60px), меню раскрывается вверх (`column-reverse`), прячется вместе с вуалью, когда виден `.footer`; `.sticky_fade` внизу (перевёрнут `scaleY(-1)`, цвет берётся по нижнему краю экрана); `.plan_download` пока скрыт.
- Мобилка: скролл нативный (Lenis на тач не сглаживает, `syncTouch: false`); баннеры вилл примагничиваются CSS `scroll-snap-type: y proximity` на `html` + `scroll-snap-align: center`. Поэтому якоря меню на мобилке идут через нативный `scrollTo` (`goTo()` в `scripts.js`), а не через Lenis.
- Видео просто играют по кругу, на паузу за экраном их не ставим (пауза/перезапуск на iOS давали чёрные кадры). `firstCardScale()` (scale первой белой карточки) на мобилке выключен: iOS переставал рисовать видео архитектуры внутри скруглённой `overflow: hidden` карточки, пока у неё меняется `transform` (белый блок при возврате наверх). Видео внутри таких карточек не анимировать `transform`ом предков.
- Футер на мобилке: «Соц. мережі» перед «Контакти» (`order`, колонки `auto 1fr`), нижние строки по левому краю.
- `.lots .carousel` на мобилке `display: contents` — у него нет бокса, поэтому подгрузка карусели наблюдает `.carousel_track`.
- Футер на мобилке с рамкой как на десктопе: `--inset` 12px→6px, снизу 6px. Телефона в hero нет, заголовок на `28svh`, кнопка меньше (14px) и на 10svh + 24px над низом. Hero = `100lvh + 5vh + 20px` (белая карточка начинается за краем экрана), кнопка привязана к `svh`.
- Вкладки «Концепції» на мобилке (все 4, вместе с «Інфраструктура»): `.gallery_tabs` обёрнут в `.gallery_tabs_wrap` с кнопкой `.gallery_tabs_more` (шеврон «>» = следующая вкладка). Если вкладки не влезают, JS ставит `is-overflow`: пилюля = прокручиваемая полоса + шеврон, края полосы растворяются маской (`fade_start`/`fade_end`), активная вкладка центрируется. На десктопе обёртка `display: contents`, шеврона нет. Для других галерей — та же разметка.
- Галереи запускают первое видео, когда край блока подходит к экрану (iOS показывает ещё не запущенное видео чёрным).
